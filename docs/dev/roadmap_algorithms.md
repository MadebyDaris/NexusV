# Algorithms to implement
In modular arithmetic, Barrett reduction is an algorithm designed to optimize the calculation of ${\displaystyle a\,{\bmod {\,}}n\,}$ without needing a fast division algorithm. It replaces divisions with multiplications ${\displaystyle a<n^{2}}$. It was introduced in 1986 by P.D. Barrett.

In modular arithmetic computation, Montgomery modular multiplication, more commonly referred to as Montgomery multiplication, is a method for performing fast modular multiplication.
